# Demo 测试问题集

## 一、命中知识库的问题

### 1. 质量问题退货运费

```text
质量问题退货运费谁承担？普通快递最高报销多少？请直接回答。
```

预期要点：

- 非人为质量问题。
- 签收后 15 日内提交售后申请。
- 凭证审核通过。
- 退货、换货或维修往返运费由平台承担。
- 用户自行寄回时普通快递最高报销 12 元。
- 不建议到付，保留快递单号。

### 2. 非质量问题退货

```text
如果不是质量问题，我不想要了，退货运费谁承担？
```

预期要点：

- 非质量问题退货由用户承担寄回运费。
- 商品需保持外包装、配件、赠品、说明书完整。
- 不影响二次销售。

### 3. 退款到账时间

```text
退货退款一般多久到账？
```

预期要点：

- 仓库签收并完成质检后处理。
- 普通商品质检 1 到 3 个工作日。
- 大件商品 3 到 5 个工作日。
- 微信、支付宝通常 1 到 3 个工作日到账。
- 银行卡通常 3 到 7 个工作日到账。

### 4. 会员权益

```text
金卡会员每个月有什么优惠券？
```

预期要点：

- 金卡会员每月可领取 2 张满 199 减 20 优惠券。
- 享受生日月 9 折券。

### 5. 价格保护

```text
商品签收后降价可以申请价格保护吗？
```

预期要点：

- 签收后 7 日内。
- 同一商品同规格。
- 官方降价可申请价格保护。

## 二、知识边界与规则约束

### 1. 知识库没有明确规则

```text
海外退货运费可以报销多少？
```

预期要点：

- 知识库中没有明确说明。
- 建议联系人工客服确认。

### 2. 知识库已有明确规则

```text
积分可以提现吗？
```

预期要点：

- 积分不可提现。
- 可在积分商城兑换优惠券和礼品。
- 100 积分可抵扣 1 元，但单笔订单最多抵扣实付金额的 20%。

说明：该题不属于“拒答题”。它用于验证 Agent 能正确引用已有积分规则，而不是将存在于知识库中的信息误判为缺失。
